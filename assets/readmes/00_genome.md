# 00_genome — Reference Genome Files

This directory contains reference genome resources used by the pipeline. Files are only written here when `--save_reference` is specified at run time.

## Subdirectories

| Path | Contents |
|------|----------|
| `target/` | Target genome FASTA, chromosome sizes, BED annotation, and GTF |
| `target/index/` | Bowtie2 index files for the target genome |
| `spikein/index/` | Bowtie2 index files for the spike-in genome |
| `annotation/` | Genome annotation files derived from the GTF (e.g. gene BED) |

## How These Files Are Derived

- **FASTA** — Provided directly by the user (`--fasta`) or downloaded from iGenomes (`--genome`).
- **Bowtie2 indices** — Built from the FASTA by `bowtie2-build`. Building indices is time-consuming; saving them here with `--save_reference` allows them to be reused across pipeline runs by pointing `--bowtie2` (and `--spikein_bowtie2`) to this directory.
- **BED / GTF** — The pipeline converts the input GTF to a BED file for downstream tools (e.g. deepTools heatmaps). The original GTF is also copied here if `--save_reference` is set.
- **Chromosome sizes** — Generated by `samtools faidx` on the FASTA and used by bedGraphToBigWig and related tools.

## When to Re-use Saved Indices

Pass the saved index paths back on the command line:

```bash
nextflow run main.nf \
  --bowtie2 results/00_genome/target/index/ \
  --spikein_bowtie2 results/00_genome/spikein/index/ \
  ...
```

This skips the index-building step entirely and can save significant wall-clock time.
